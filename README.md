# Claude Code额外用量攻略：怎么买官方用量套餐？额度为什么见底快？API 和第三方渠道哪个省钱？（附 $1 立减优惠码）

正写着代码，终端里弹出一句 "You've hit your session limit"——这大概是 Claude Code 用户最不想看到的一行字。订阅额度不是无限的，而编码偏偏又是 Claude 全家桶里最费额度的一项：一次会话动辄几十轮请求，每轮都带着完整上下文。

所以「Claude Code额外用量怎么买」这个问题，本质上要回答三件事：官方的额外用量怎么买、多少钱；额度为什么掉得比你想的快；以及除了官方，还有没有别的路。这篇文章把几条路径都捋一遍，包括各自的成本和适合的人群。

## 先搞清楚：你的额度是怎么见底的

Claude 的付费订阅里，聊天和 Claude Code 共用一个额度池。会话限额每 5 小时重置一次，每周还有一个在固定时间重置的周限额——重置时间由系统分配给你的账户，在用量页面可以查到。云端会话也计入同一个池子，不单独收费。

编码费额度的原因很直接：每次请求都会发送截至当前的完整对话。每调用一次工具、读一个文件、跑一轮测试，都会再发一次请求并附带上一次的结果。提示缓存能缓解这个问题，但订阅的缓存只保留一小时。上午挂着一个长会话，午饭回来发的第一条消息，会因为缓存过期而重新处理整个上下文——这一条消息的消耗可能超过之前 20 条的总和。

社区里的实际反馈差距很大：有 Pro 用户说 30 分钟就烧完了一个 5 小时窗口；也有 Max 20x 用户在周日重置后，周二早上就跑掉了周额度的 86%。9 月下旬 Opus 5.5 成为默认模型时，5 小时窗口的额度有过上调，整体松动了一些，但「额度掉得快」这个基本盘没变。

> 一个常被误读的点：切换模型并不能恢复会话或周限额，这两个窗口对所有模型生效。只有当提示是 "You've hit your Opus limit" 这类模型专属限额时，用 /model 换个模型才有用。

想看额度去哪了，在 Claude Code 里运行 /usage：按 d 看最近 24 小时，按 w 看最近 7 天。占比达到 10% 以上的消耗项会被单独标出，比如上下文过长、缓存未命中，还能归因到具体的 skills、subagents、插件或 MCP 服务器。注意这部分归因只统计当前这台电脑上的本地会话，在别的设备或网页端产生的用量不在其中。

这是 Anthropic 官方给的正路：预先购买使用量套餐，比标准额外用量费率最多能省 30%，面值越大折扣越深。

| $250 | 20% | $200 |

几个关键规则：

- 套餐适用于 Pro、Max 和 Team 计划。
- 个人 Pro 和 Max 用户每月最多购买 $2000 面值的折扣套餐；Team 计划所有者的上限是 $3000。超过上限仍可以继续用额外用量，但超出部分按标准费率计费，没有折扣。
- 余额是一个统一的池子：Claude 网页版、桌面端、手机 App、Claude Code、Cowork，以及用你 Claude 账户登录的第三方产品，都从这里扣。
- 套餐不替代订阅自带额度。套餐内的部分照常工作，余额只在你超出限额后才扣。
- 同一个月可以买多档，买满月上限为止，折扣在结账时自动生效。

购买步骤：先确认账户已开启额外用量，然后进设置 > 使用量，点「购买使用量」，选套餐大小并确认。余额会显示在用量仪表板里，随着超出限额的使用逐渐扣减。

价格和规则以官方页面实时显示为准——Anthropic 保留调整价格和计划的权力，这句话不是客套，过去一年订阅价格确实动过几次。

## 开了额外用量之后，留意缓存的变化

很多人开了额外用量之后才发现的一个细节：一旦开始消耗用量余额，提示缓存的保留时间会从一小时降到 5 分钟。

> 也就是说，过去一顿午饭的间隙不会产生任何费用；开了额外用量之后，同样的空闲间隔，回来第一条消息就会按正常费率重算整个上下文。

对策倒不复杂：不相关的任务之间用 /clear 清掉上下文（这个操作本身免费），该压缩的长会话就压缩，一批任务跑完就收尾。缓存省下来的钱，往往比你以为的多。

另一条路是 API 按量计费。当前每百万 token 的价格：Opus 5.5 输入 $4、输出 $20；Sonnet 5 输入 $2、输出 $10；Haiku 4.5 输入 $1、输出 $5；Fable 5.1 输入 $10、输出 $50。缓存读取另算，每百万 $0.10 到 $0.25 不等。官方给企业场景的参考数字是：平均每个开发者每个活跃日约 $13，每月 $150–250，90% 的用户每天不超过 $30。这个模式适合自动化任务、夜间跑批和 CI 步骤——这类突发运行不该和你的交互式工作抢同一个额度池。

顺带说一个经典事故：如果在服务器或常用 shell 里设置过 ANTHROPIC_API_KEY 环境变量，Claude Code 会优先用这个密钥认证，工作全部按 token 计费。你的订阅额度一动不动，账单却在悄悄涨。怀疑账单不对时，先跑 printenv ANTHROPIC_API_KEY 检查，有输出就 unset 掉，再用 /usage 和 /status 确认当前计费方式。

还有一点值得知道：Fable 这类旗舰模型在 Pro 和 Team Standard 上不走套餐内额度，从第一笔请求起就按用量余额计费；在 Max 和 Team Premium 上，最多可以占到周限额的一半。开了额外用量又常用 Fable 的话，消耗会比看起来快不少。

## 常见问题

**用量套餐会替代我订阅里自带的额度吗？**
不会。套餐内额度的工作方式完全不变，余额只在你超出限额、开始消耗额外用量后才扣。

**同一个月可以买多档套餐吗？**
可以，直到触及月度上限（个人 Pro/Max 为 $2000 面值，Team 为 $3000）。超过上限仍能用额外用量，只是超出部分按标准费率、无折扣。

**额度用完只能干等吗？**
三条路：等重置（5 小时或每周）、升级套餐、开启用量余额继续用。开启后超出部分按 API 费率计费，Pro 和 Max 用户可以用 /usage-credits 管理这项设置。

**怎么确认自己走的是订阅还是 API 计费？**
在 Claude Code 里运行 /usage 或 /status：订阅用户看到的是套餐用量条，API 账户看到的是带 token 成本的会话信息、没有用量条。服务器环境下先检查 ANTHROPIC_API_KEY 是否被设置过。

**余额能用在哪些地方？**
Claude 网页版、桌面和移动端 App、Claude Code、Cowork，以及用你 Claude 账户登录的第三方产品，都从同一个余额池扣。
